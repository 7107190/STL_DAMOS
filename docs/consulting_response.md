### 환경과 범위

- vvu: Ryzen 5 9600X, RTX 5060 Ti 16GB, PyTorch 2.7.0+cu128/CUDA runtime 12.8. 단일 호스트의 독립 프로세스, TCP loopback.

- 모빌리티별 RGB 6방향 800x450 4시점 + 현재 일반 LiDAR 1프레임. 제공 체크포인트·후처리 유지, 실제 CUDA 모델·Groth16·송수신·검증·Ego 병합 수행.
- 맑은 낮·폭우·야간에 각각 새 S5 장면 1개. 장면당 고장 15종, 조건당 정상 3회·고장 1회·복귀 3회. 총 45개 조건·315라운드 실행 완료.
- S1~S9는 기존 100건 평가의 비정상 상황 종류. 이번 고장 대응 시험은 S5만 대상. 기본 Scenic의 저각 햇빛·짙은 안개 전용 조건·젖은 야간 조건과의 고장 조합은 미평가.
- 비교용 Ego 정지 유지, 정지 필요 조건에서만 별도 초기 2m/s 저속 제동 확인. 자연 주행 회피·운행 자동 재개·고장 상태 장애물 탐지정확도 시험과 구분.

모든 품질 기준은 고장 이름·Scenic GT가 아니라 수신 raw 데이터·직전 정상 입력·센서 보정값에서 계산. 정상 감시자 출력으로 대체 가능하면 DEGRADED_COOPERATIVE, 정상 데이터 3회 연속 확인 후 NORMAL 복귀. 로컬 불량 후보는 증명·전송·병합 전에 제외하며, 해당 노드의 공유 관측 마스크는 0으로 표시.

F02의 실처리 조건은 강한 흐림 대표 1종. 가림·색 이상·흔들림까지 실처리 검증했다는 뜻이 아님. F04~F06도 위 강도·형태의 지정 고장만 대상이며, 임의의 작은 노이즈·정상 범위 안의 거짓 포인트를 모두 탐지한다는 주장은 하지 않음. 품질 비교는 정지 배경의 직전 정상 참조가 있다는 조건.
F03는 CARLA가 센서 패킷에 제공하는 실측 transform 메타데이터를 이용한 장착 일치 검사. 실차에서 장착 자세를 추정·보정하거나 고장 센서를 자동 수리하는 기능 검증은 아님. 시험의 정상 복귀 단계는 고장 주입을 해제한 뒤 정상 데이터 3회를 확인하는 방식.

### 독립 검증과 자료

- 추가 5종의 고장 라운드마다 주입 전·후 raw, 정상 참조 raw, 실제 모델 입력, 손상 모델 후보 출력, 송신 본문·증명, 수신 BEV·병합·상태 보존.
- 실제 재부착 센서 ID·선언/실제 장착 행렬·복귀 기록 보존. raw로 주입 및 품질 검사를 재현하고, 전처리 입력·저장 병합 배열·상태를 독립 재계산.
- 손상 모델 후보를 같은 체크포인트로 CUDA 재실행. 입력·관측 마스크·pose는 정확 일치 검사, FP16 확률은 최대 오차 0.01·평균 오차 0.0001 이하 및 실제 오차 기록. 확률의 비트 단위 일치 주장은 하지 않음.
- 예비 감사의 처음 확률 비교에서 최대 0.003174 차이로 0.002 오차 비교가 실패. 본 시험 전 위 수치 재현 기준을 고정하여 `protocol.json`에 명시. 고장 상태 전환·불량 데이터 배제·정상 복귀 판정 기준은 완화하지 않음.
- 예비시험 `/home/vvu/vv/_Data/Carla/Columbus/DAMOS_results/resilience_20261024_smoke_v1`: 35라운드·실제 증명 70개·주입 5건 재현·손상 모델 재실행 5건 검증.
- 본 시험 `/home/vvu/vv/_Data/Carla/Columbus/DAMOS_results/resilience_20261024_all15_v1`: 계획·소스/설정 스냅샷·환경·날씨별 실행·판정·독립 감사·그림 보존. 기존 시험 및 제출 ZIP 덮어쓰기 없음.
- 실제 야간 서버 조회는 `observed_night_and_software.json`에 보존: sun_altitude=-90, precipitation=0, wetness=0, fog_density=60. `ClearNight` 프리셋에도 안개 성분은 있으나, 기본 Scenic의 짙은 안개 전용 조건(fog_density=100)·젖은 야간(wetness=95)과 동일한 조건은 아님.

### 보조 모델 수치 재현 미달

| 조건 | 최대 확률 차이 | 평균 확률 차이 | 판정 |
|---|---:|---:|---|

원인 미확정. 동일 raw·전처리 입력과 체크포인트 해시를 확인했으나 모델 재실행 확률은 완전 재현되지 않음. FP16 또는 선택적 리파인먼트 경계 영향은 추정이며, 원인으로 확정하지 않음. 모델 수치 재현 문제는 추가 조사 대상.

두 후보는 원래 품질 검사에서 제외되어 전송·최종 병합에 사용되지 않음. 최종 병합은 정상 감시자 데이터로 정확 재계산됐으므로 기능 대응 45개 판정과 별개. 수치 기준을 넓히거나 후보 예측을 수정해 통과시키지 않음.

`audit_v2.json`: `all_saved_arrays_and_states_consistent=true`, `inference_replay_within_limits=false`. 감사 명령은 모든 자료 검사를 완료하고 결과 JSON을 저장한 뒤 종료 코드 2 반환. 이는 시뮬레이션 실행 실패나 불량 후보 병합을 뜻하지 않으며 보조 수치 검사의 미달 표시.
첫 중단형 감사 대신 전체 미달을 수집하는 감사 도구 버전은 `auditor_v2.py`·`audit_v2_provenance.json`에 보존. 본 시험의 주입/대응 판정 기준은 그대로 유지. 그림 후처리의 가독성 보완은 `figures_v2/renderer.py`·`rendering_provenance.json`으로 별도 기록하며 원 `figures_v1/` 및 실행 당시 스냅샷은 보존.

## 2. 강건한 서비스 정의

### 서비스 대상

Ego가 자신의 인지 데이터와 주변 감시자의 인증된 동시점 BEV를 병합하여 이상상황의 장애물 존재·위치를 확인하는 협력 인지 서비스.
현재 범위는 CARLA, Ego 차량 1대, 60m 이내 감시자 1대, 단일 호스트·독립 프로세스·TCP loopback.
감시자끼리 통신·경로계획·운행 복구는 포함하지 않음.

이번 시험에서 강건함은 모든 고장의 무조건 극복이 아니라 **유효 데이터 기반의 협력 출력 유지 또는 정보 부족의 명시적 표시와 보수적인 정지 판단, 정상 데이터 복귀 확인**으로 정의.

### 상태와 전환 기준

| 상태 | 진입 기준 | 출력·대응 |
|---|---|---|
| NORMAL | 정상 로컬 입력, 현재 프레임의 검증된 감시자 출력, 복귀 연속 조건 충족 | 로컬+감시자 BEV 병합 |
| DEGRADED_COOPERATIVE | 로컬 입력/출력 불량, 현재 프레임의 검증된 감시자 출력 존재 | 로컬 불량 데이터 배제, 감시자 기반 병합, 성능 저하 상태 명시 |

RECOVERING에서 새 장애가 발생하면 연속 회수 초기화. 정상 3회 연속 후 NORMAL 복귀.
정상 복귀는 **인지 서비스의 상태 복귀**이며 자율주행·모빌리티 운행의 자동 재개가 아님.

### 데이터 유효성 기준

- RGB raw 크기·프레임·동기 시각 검사. 픽셀 99.99% 이상이 정확히 RGB 0이면 신호 소실로 처리. 일반적인 블러·가림·악천후를 모두 감지하는 판별기는 아님.
- 일반 LiDAR 데이터 유무·수치 유효성·현재 프레임 확인.
- 이전 raw 입력 지연, 이전 실제 인지 출력 유지 시 원래 프레임·시각 보존. 현재 데이터로 재표시하지 않음.
- 감시자 패킷은 등록 송신자·actor ID·수신자·session·round·frame·capture 시각·모델 일치·본문 해시·실제 Groth16 증명 검사.
- 불량 패킷은 병합에서 배제하되 수신 처리를 즉시 종료하지 않고 고정된 원래 제한시간까지만 정상 패킷 대기.
- 수신 제한 8초, 시험용 결과 노후화 상한 20초. 후자는 저장 대기까지 포함한 부모 프로세스 구간으로, 성능지표 2번의 18초 계측 구간·판정과 별개인 공학적 시험 설정.
- 유효 감시자 BEV 3셀 이상은 출력 가용성 확인용. 이상상황 정답과 3셀 이상 겹침·0.5초 연속 탐지라는 기존 정확도 성공 조건과 다름.
- 로컬 입력을 사용할 수 없으면 valid=0인 좌표 정렬용 unknown 참조만 생성. 이를 실제 모델 예측이나 로컬 인지 성공으로 기록하지 않음.

ZKP는 송신자·데이터 결합을 검증하며 센서의 물리적 진실성·모델 정확성을 증명하지 않음. 정상 등록 송신자가 거짓 인지 결과를 정상 증명과 함께 보내는 공격은 이번 시험의 방어 범위 밖.
