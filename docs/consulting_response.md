## 2. 강건한 서비스 정의

### 서비스 대상

Ego가 자신의 인지 데이터와 주변 감시자의 인증된 동시점 BEV를 병합하여 이상상황의 장애물 존재·위치를 확인하는 협력 인지 서비스.
현재 범위는 CARLA, Ego 차량 1대, 60m 이내 감시자 1대, 단일 호스트·독립 프로세스·TCP loopback.
감시자끼리 통신·경로계획·운행 복구는 포함하지 않음.

이번 시험에서 강건함은 모든 고장의 무조건 극복이 아니라 **유효 데이터 기반의 협력 출력 유지 또는 정보 부족의 명시적 표시와 보수적인 정지 판단, 정상 데이터 복귀 확인**으로 정의.

### 상태와 전환 기준

| 상태 | 진입 기준 | 출력·대응 |
|---|---|---|
| NORMAL | 정상 로컬 입력, 현재 프레임의 검증된 감시자 출력, 복귀 연속 조건 충족 | 로컬+감시자 BEV 병합 |
| DEGRADED_COOPERATIVE | 로컬 입력/출력 불량, 현재 프레임의 검증된 감시자 출력 존재 | 로컬 불량 데이터 배제, 감시자 기반 병합, 성능 저하 상태 명시 |
| SAFE_STOP | 유효한 감시자 출력 부재, 출력 비관측, 처리 결과 노후화 | 협력 인지 확보 불가 명시, 시험용 정지 요구 |
| RECOVERING | 장애 후 정상 로컬 입력과 검증된 감시자 출력 복귀 | 정상 데이터 3회 연속 확인 전 정지 요구 유지 |

RECOVERING에서 새 장애가 발생하면 연속 회수 초기화. 정상 3회 연속 후 NORMAL 복귀.
정상 복귀는 **인지 서비스의 상태 복귀**이며 자율주행·모빌리티 운행의 자동 재개가 아님.

### 데이터 유효성 기준

- RGB raw 크기·프레임·동기 시각 검사. 픽셀 99.99% 이상이 정확히 RGB 0이면 신호 소실로 처리. 일반적인 블러·가림·악천후를 모두 감지하는 판별기는 아님.
- 일반 LiDAR 데이터 유무·수치 유효성·현재 프레임 확인.
- 이전 raw 입력 지연, 이전 실제 인지 출력 유지 시 원래 프레임·시각 보존. 현재 데이터로 재표시하지 않음.
- 감시자 패킷은 등록 송신자·actor ID·수신자·session·round·frame·capture 시각·모델 일치·본문 해시·실제 Groth16 증명 검사.
- 불량 패킷은 병합에서 배제하되 수신 처리를 즉시 종료하지 않고 고정된 원래 제한시간까지만 정상 패킷 대기.
- 수신 제한 8초, 시험용 결과 노후화 상한 20초. 후자는 저장 대기까지 포함한 부모 프로세스 구간으로, 성능지표 2번의 18초 계측 구간·판정과 별개인 공학적 시험 설정.
- 유효 감시자 BEV 3셀 이상은 출력 가용성 확인용. 이상상황 정답과 3셀 이상 겹침·0.5초 연속 탐지라는 기존 정확도 성공 조건과 다름.
- 로컬 입력을 사용할 수 없으면 valid=0인 좌표 정렬용 unknown 참조만 생성. 이를 실제 모델 예측이나 로컬 인지 성공으로 기록하지 않음.

ZKP는 송신자·데이터 결합을 검증하며 센서의 물리적 진실성·모델 정확성을 증명하지 않음. 정상 등록 송신자가 거짓 인지 결과를 정상 증명과 함께 보내는 공격은 이번 시험의 방어 범위 밖.

### 기존 성능 근거

- 처리속도: 동일 입력 반복 135회 정상 완료, 최대 1.911553289초.
- 탐지정확도: 신규 장면 100건, 성공 90건, 성공률 90%. 실패·자료 오류 10건 포함.
- 두 결과는 기존 지정 조건의 성능 근거이며 고장 주입 상태의 정확도·실도로 운행 안전성까지 확장하지 않음.

## 4. CARLA 장애 대응 시험

### 시험 구성

- Scenic이 생성한 S5 이상상황과 Ego·배달로봇 감시자 사용. 각 객체 실제 6방향 RGB 4시점·현재 일반 LiDAR 기반 입력.
- 기본 조건: ClearNoon, HardRainNoon, ClearNight. 날씨별 새 서버·새 S5 장면 1개, 같은 장면에서 10종 장애 조건 반복.
- 독립 이상상황 30건이라는 뜻이 아니라 **3개 S5 장면에서 고장×날씨 30개 조건** 검증.
- 각 조건은 정상 3회, 고장 1회, 복귀 3회. 총 7회의 실시간 센서 취득·실제 CUDA/통신 처리.
- 센서 취득 시뮬레이션 tick 소유자는 Scenic. 시험 코드가 증명 속도에 맞춰 CARLA tick을 대신 진행하지 않음.
- 비교용 Ego는 차도에서 정지 유지. 별도 제동 확인 때만 초기 속도 약 2m/s 설정 후 throttle=0·brake=1 적용, 속도 0.2m/s 이하·5 시뮬레이션 초 이내 정지 확인.
- 저속 제동 확인은 **상태 판단 후 별도 액추에이터 기능 확인**. 자연 주행 중 장애 발견부터 정지까지의 안전 거리·전체 지연을 측정한 시험이 아님.

## 재현 명령

vvu 기존 실행 환경 기준. GPU·디스크·CARLA 빌드·모델·ZKP 키가 준비된 환경 필요. Git clone만으로 실행 불가.

```bash
cd /home/vvu/vv/DAMOS/Carla-0.9.16-source
/home/vvu/vv/DAMOS/.venvs/bev/bin/python \
  _DAMOS/scripts/run_carla_resilience.py \
  --port 2690 \
  --output /home/vvu/vv/_Data/Carla/Columbus/DAMOS_results/새_장애대응시험

/home/vvu/vv/DAMOS/.venvs/bev/bin/python \
  _DAMOS/scripts/audit_carla_resilience.py \
  /home/vvu/vv/_Data/Carla/Columbus/DAMOS_results/새_장애대응시험 \
  --real-crypto \
  --output /home/vvu/vv/_Data/Carla/Columbus/DAMOS_results/새_장애대응시험/audit.json
```

현재 launcher는 실행 전 소스 9개를 `frozen_source/`에 자동 저장하고, 저장한 바이트 기준 SHA-256을 `protocol.json`에 기록. 기존 결과 폴더 덮어쓰기와 이미 사용 중인 CARLA 포트 교체 거부. 지정 조건 미완료·실패 시 정상 성공으로 종료하지 않음.
2026-10-14 실행 소스와 이후 재현 도구 보완은 구분하며, 보존된 과거 시험 코드·결과는 덮어쓰지 않음.
실행은 시험용 launcher가 `DAMOS_RESILIENCE_PLAN`을 설정하는 opt-in 경로. 일반 실행에서 해당 변수가 없으면 기존 BEV 경로 유지.
