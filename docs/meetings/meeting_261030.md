## 6. 기존 구현과 대조한 확인 사항

회의 발언을 기존 DAMOS 구현과 대조한 실무 확인 사항. 회의에서 완료를 확인한 결과는 아님.

- 현재 3번 지표 실패: `M3-075-S3`, `M3-082-S1`, `M3-084-S3`. 연속 탐지 약 0.4초로 0.5초 기준 미달. 원인·안전 영향의 추가 분석 대상.
- 현재 100건 평가는 장애물 존재·위치 탐지 기준. 사고 발생·회피·팬텀 브레이크를 직접 판정한 시험은 아니므로 결과 단정 금지.
- 기존 ZKP 검증은 송신자·메시지 결합·무결성 확인 범위. 정상 인증된 참여자가 의미적으로 거짓인 관측을 보내는 문제까지 해결했다고 서술하지 않음.
- 현재 BEV 모델 입력은 RGB+LiDAR. 카메라 중심 실물 PoC로 단순화할 경우 모델·센서 입력 규약 변경 검토 필요.
- 통신 상품 사양·가격, 외부 사고 사례, 협력 기관명은 제안서 인용 전 원출처 확인 필요.
