## 서브시스템1

**탈중앙형 협력 인지 시스템**

### 협력 인지 기반기술

- CARLA 기반 OPV2V 협력 데이터셋 활용.
- Ego 주변만이 아니라 협력 가능한 차량 주변까지 포함하는 인지 label 구성.
- 통신 가능한 차량 수에 맞춰 BEV feature를 생성하고 주변 차량을 예측하는 모델 구성.
- 협력 데이터 기반 비가시 영역 인지를 위한 입력·모델 구조 검토.

### ZKP 적용 검토

- V2X 환경에서 영지식 증명의 적용 가능성·인증 절차·실시간 처리 부담 검토.
- Groth16 등 비대화형 증명 절차와 증명 크기·생성 및 검증 비용 비교.
- ZK-SNARKs·ZK-STARKs·Bulletproofs의 적용 특성 검토.
- 2026년 실제 Groth16·BEV 통합 경로와 구분. 후속 구현은 [2026년 서브시스템1](2026.md#서브시스템1) 참조.

## 서브시스템2

**비정상 상황 발생 시나리오 개발**

- CARLA와 Scenic을 연결한 확률적 객체 생성·상황 트리거 파이프라인 구축.
- 환경 요인과 객체 간 상호작용을 조합한 이상상황 구성.
- 환경 요인: 야간·역광·폭우·안개 4종.
- **객체 상호작용: S1~S9 9종 개발 완료.**
- 아래 생성 수·앵커는 현재 실행 코드의 운영 설정. 시나리오의 개발 완료 연도와 구분.
- 2026년 HW·SW 고장 15종과 별개의 이상상황 목록.

**앵커·감시자:**

- 앵커: 감시·평가할 지점 또는 구역.
- 앵커 member: 그 상황을 구성하는 원래 객체.
- S1~S4는 개별 객체, S5~S9는 구역·군집 기준.
- 감시자는 앵커당 1대.
- 인도 배치·상황 방향 감시 유지.

**시나리오·날씨 선택:**

- `--n-scenarios 3`: 서로 다른 최대 3종을 **동시에** 실행.
- 한 실행의 날씨: 네 기본 preset 중 하나.
- 기본 preset: `low_sun`, `heavy_rain`, `dense_fog`, `wet_night`.
- 날씨 정의: [공유 JSON](../Carla-0.9.16-source/_DAMOS/_scenarios/weather_presets.json).
- 일반 실행: Low 품질.
- 실제 안개·후처리 효과 검증: Epic 품질.

## 서브시스템3

**합성 공간 지능 디지털 트윈 기반기술**

### 복합 모빌리티·데이터 수집

- CARLA에 자동차·휴머노이드·배달로봇 3종 모델·동작과 가상 센서 구성.
- RGB·Depth·Semantic Segmentation·LiDAR 등 센서 데이터 취득·저장 SW 구현.
- KITTI 구조를 참고한 데이터셋 구성.
- 객체의 위치·속도·방향·취득 시각 등 협력 데이터 송수신 기반 구현.
- 2026년 데이터셋 종류·대수·용량의 최종 집계는 [성능지표 1번](metrics.md#1번-모빌리티-종류대수와-데이터셋)에서 별도 관리.

### 장기 미래 궤적 예측

| 항목 | 내용 |
|---|---|
| 데이터 | Argoverse2 motion forecasting |
| 관측 | 과거 5초, 위치·속도·차선 및 주변 객체 정보 |
| 모델 | QCNet 기반 변형 |
| 출력 | 미래 최대 6초, 최대 6개 궤적 후보 |
| 학습·평가 | 확률 기반 손실, minADE·minFDE, 지도 위 예측·정답 비교 |

- 도로 지도·차량 상태·주변 차량 상호작용을 함께 고려.
- 최적 체크포인트 선정과 다중 모드 궤적 시각화 구성.
- 원 보고서의 미래 6초 출력과 10초 목표 설명을 구분. 10초 달성으로 기재하지 않음.

### 협력 인지 기반 궤적 예측

| 항목 | 내용 |
|---|---|
| 데이터 | OPV2V |
| 입력 | 과거 1초·10스텝의 Ego 및 주변 최대 8대 상태, 3채널 BEV |
| 구조 | Hybrid Scene-Aware Encoder, 상태공간 모델·Transformer 기반 Hybrid Decoder |
| 출력 | 미래 3초·30스텝, 최대 6개 궤적 후보 |
| 평가 | minADE·minFDE, 주행 가능 영역 제약, 예측·정답 시각화 |

### 컨설팅 보완 요청

2026년 컨설팅에서 제기된 장기예측 설명 보완. 아래 내용은 과거 구현 완료 성과가 아닌 **박준범 작성 대기·검토 계획**.

### 1. 장기 미래예측 목표 구체화

**작성 위치·담당:**

- 박준범 작성. 1단계 단계보고서의 1차년도 수행 내용 → 서브시스템3 마지막 항목에 장기예측 보완의견 추가 권장. 기존 장기 미래예측 절을 근거로 작성.
- 소제목 예시: 장기예측 목표 및 기술 보완의견 반영. 과거 제출본을 덮어쓰거나 2차년도 신규 성과로 중복 기재하지 않음.
- 1차년도 제출 원문은 과거 5초 입력·미래 6초 궤적 출력 설명. 10초 목표의 필요성과 실제 구현·검증 결과를 구분하여 작성.

별도 2026년 제출평가 결과는 [성능지표 4번](metrics.md#4번-미래예측-지평과-유효-생성) 참조.

**기존 PPT의 확장 검토안:**

- 아래는 기존 검토안이며 10초를 새로운 2단계 확정 목표나 구현 완료 성과로 취급하지 않음. 담당자 검토 후 연차별 성과·미달/보완·후속 계획 구분.
- 미래 10초·100시점 출력, 관측 5초+정답 10초 평가셋 구성.
- 신규 진입·관측 누락: 가변 이력·누락 마스크·문맥 갱신 검토.
- 의도 불확실·후보 점수 과신: 행동 후보·점수 보정 검토.
- 동일 하드웨어·객체 수에서 8/10초 오차와 CARLA 연동 20FPS 목표 검증.

### 3. 최신 기술 검토와 적용 계획

예측 담당 보완 자료의 검토 후보. 이 저장소에서 세 기술을 구현·성능 검증했다는 의미는 아님.

| 검토 후보 | 보완 대상 | 계획상 반영 위치 |
|---|---|---|
| SHARP | 짧거나 누락된 관측 이력 | 입력부: 가변 이력·누락 마스크·문맥 갱신 |
| FutureLift | 먼 미래의 경로 오차 | 디코더: 10초 출력·전체 경로 보정 |
| DONUT-NLL | 후보 점수와 실제 정확도의 불일치 | 출력부: 모드 점수 점검·과신 보정 |

- 현재 대응: 보완 PPT에 검토 후보·적용 위치·비교평가 계획 정리.
- 후속 작업: 담당자 모델 적용 후 출력 길이만 늘린 기준 모델과 동일 조건 비교.
- 8/10초 minADE·minFDE, 1/3/5초 성능 유지, 같은 하드웨어의 처리속도 평가 계획.
- 박준범이 1차년도 장기예측 절의 보완의견으로 검토 결과 작성. 적용·비교평가 완료 여부를 구분하고, 확정한 후속 개발만 2단계 계획과 연결.

**추가 작성 원고:**

- `보고서_개인_초안/보고서_jb.hwpx`의 장기예측·복합 모빌리티 예측 본문이 1차년도 최종보고서에 반영된 것을 대조 확인.
- 해당 원고에 피드백 1·3 설명 보완, 성능지표 4번 달성 내용 추가 요청 범위 정리.
- 성능지표 4번은 **2차년도 수행·검증 결과로 구분**하여 작성. 이후 1단계 단계보고서에 통합.
- 세부 수치·증빙은 [성능지표 4번](metrics.md#4번-미래예측-지평과-유효-생성) 참조.
