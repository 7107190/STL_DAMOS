# DAMOS 진행·제출 준비 현황

기준일: 2026-10-31. NAS 최신 보고서·시험신청서·메타데이터 ZIP·성과물과 현재 문서 대조.

**핵심 정리:**

- ✅는 해당 작업 또는 증빙 확보 완료. 내부 검증과 기관 접수·성적서 발급은 별개.
- 1단계 단계보고서: 2025~2026년 성과를 통합하는 보고서. 기존 두 파일을 그대로 이어 붙이는 방식과 구분.
- 현재 통합 HWPX는 2차년도 수행 과정·내용 부분. 전체 단계보고서 완성본은 아님.
- 연도 분류 확정: 객체 상호작용 S1~S9 9종은 2025년 완료 성과. 2026년에는 활용·감시자·센서·협력 인지 통합·평가로 구분.
- 기술문서·PoC 보고서는 별도 두 건이 아닌 **기술·PoC 통합보고서 1건**으로 준비.
- 2단계 연구계획은 단계보고서의 향후 수행계획에 반영. 별도 제안서 파일 제출 여부는 미확인.

**단계보고서의 추가 위치:**

- 피드백 1·3: [2025년 서브시스템3의 보완 요청](2025.md#컨설팅-보완-요청). 담당 박준범.
- 작업용 원고: 1차년도 보고서 폴더의 보고서_개인_초안/보고서_jb.hwpx. 기존 예측 본문이 최종본에 반영된 것을 대조 확인.
- 같은 원고에 성능지표 4번 달성 내용도 추가하되, 해당 내용은 2차년도 수행 결과로 구분. 작성본은 1단계 단계보고서에 통합.
- 피드백 2·4: 2차년도 서브시스템2 마지막 다항에 반영 완료.
- 피드백 5: 2차년도 서브시스템3-2 마지막 사항에 반영 완료.
- 성능지표 4번: 2차년도 수행내용에 예측 방법·검증 과정 추가. 단계 전체 목표 달성도에 결과 요약.
- 이예린의 카메라 기반 미래 BEV 예측 연구와 별도 EdgeSSM 성능지표 4번 평가를 구분.

**기술·PoC 통합보고서:**

- 협약의 1단계 2차년도 결과물: "지상 모빌리티 대상 DMOS 동작 시뮬레이션 (Proof of Concept 보고서) 및 관련 지재권 출원서".
- 기술문서는 문서의 큰 범주, PoC 보고서는 구현·동작 검증을 담는 기술문서의 형태.
- 별도 두 파일 제출이 필수라는 명시는 확인되지 않음. 1건 통합 작성 방향.
- 구성: 시스템 설명 → 구현 방법 → 시험 방법 → 검증 결과 → 결론.
- [연도별 수행내용](2026.md)은 구현·연구·검증 기록. 올해 제출용 기술·PoC 보고서 최종본 확보와 구분.
