# DAMOS

자동차·휴머노이드·배달로봇이 인지 정보를 공유해 **가려진 이상상황을 확인하는 협력 시뮬레이션 시스템**.

**CARLA·Scenic → RGB·LiDAR 인지 → Groth16 직접 공유 → Ego BEV 병합·탐지**

## 연도별 수행내용

| 연도 | 주요 성과 | 상세 |
|---|---|---|
| **2025** | 협력 인지·데이터 수집·미래예측 기반기술, **이상상황 S1~S9 9종 개발** | [2025년 수행내용](docs/2025.md) |
| **2026** | ZKP 공유 통합, **고장 15종·60조건 대응**, 미래 BEV 연구, 기존 시나리오 활용 통합·평가 | [2026년 수행내용](docs/2026.md) |

각 연도 문서 안에서 서브시스템별로 정리.

## 성능지표

| 지표 | 현재 결과 | 상태 |
|---|---|---|
| 1. 모빌리티·데이터셋 | 3종 구현. 동시 대수·상호관측·200GB 최종 집계 대기 | 부분 완료 |
| 2. 처리속도 | 135/135회 완료, **최대 1.912초 ≤ 18초** | ✅ 내부 검증·자료 완료 |
| 3. 이상상황 탐지정확도 | 100건 중 97건 성공, **97% ≥ 70%** | ✅ 내부 검증·자료 완료 |
| 4. 미래예측 | 5,500시점 모두 **5초 지평 충족**, 유효 생성률 100% | ✅ 내부 검증·자료 완료 |

미래예측은 별도 모델·평가 경로. 위 수치는 내부 검증이며 기관 성적서 발급과 구분.
평가 방법·정확한 수치·증빙 위치: [성능지표](docs/metrics.md).

## 보고서·제출 준비

- ✅ 2차년도 수행내용 통합, 피드백 2·4·5 본문 반영.
- 박준범 추가 작성 대기: 피드백 1·3, 성능지표 4번 달성 내용.
- 1단계 단계보고서·기술/PoC 통합보고서 1건·2단계 계획 및 기관 증빙 준비 중.
- 전체 체크표: [준비 현황](docs/status.md).

## 업무 배분과 2단계 준비

**2단계 연구계획 구상을 시작하되, 남아 있는 1단계 마무리와 병행.** 아래는 업무 배분·준비 계획이며 수행 완료 결과와 구분.

### 전체 업무 배분안

| 담당 | 우선 업무 | 확보할 결과물 |
|---|---|---|
| **김기웅** | 1단계 보고서 통합, 기술·PoC 보고서 작성, 2단계 계획 총괄 | 통합 문서·전체 시스템 구성안·연차별 추진안 |
| **박형빈** | **1번 지표 최종 집계**, 실물 모빌리티·센서·컴퓨터 구성 조사 | 종류·대수·상호관측·200GB 증빙, 보유/추가 필요 장비표 |
| **손유정** | 시나리오 자료 정리, **2단계 실험 시나리오·검증 방법 설계** | 기존 시나리오의 실물 적용 가능 여부, 대표 실험·성공 기준 |
| **박준범** | 피드백 1·3, 성능지표 4번 추가 작성 | `보고서_jb.hwpx` 보완본 |
| **이서희·염주현·경다녕** | ICRAI 홍보부스 | 전시 자료·시연 구성·등록 및 현장 사진 등 홍보 증빙 |
| **이예린** | 시험신청·기관 대응 | 접수·일정·성적서 종류 확인 및 발급 진행 |
| **이성규** | 타 과제 | 당장 추가 배정 제외 |

### 김기웅·박형빈·손유정의 2단계 역할

| 담당 | 구체적으로 생각할 내용 |
|---|---|
| **김기웅: 시스템·계획** | 무엇을 입증할지, 센서→인지→공유→병합 연결 구조, 2027·2028년 개발 범위와 평가 방법 |
| **박형빈: 실험환경** | 기존 차량·PC·센서 상태, 로봇 확보 가능성, 센서 데이터 접근 방법, 추가 장비·비용 |
| **손유정: 실험설계** | 교내 통제환경에서 재현할 차폐 상황, 관찰자 배치·이동, 통신 지연·고장 조건, 성공·실패 판정 |

**회의 기준 핵심:** 실제 센서·컴퓨터·모빌리티를 연결해 협력 인지를 시연. 자율주행차 자체를 새로 만드는 계획과 구분.

**분야별 연구계획 수합:**

- 인지·예측: 이예린·박준범의 후속 연구 방향 필요.
- ZKP·공유: 홍보 담당 세 사람에게도 분야별 짧은 연구계획 초안 별도 수합.
- 단순 장비 연결뿐 아니라, 지연·불완전한 연결을 인지·예측으로 어떻게 보완할지가 연구 내용의 중심.
- 세 사람만으로 전체 기술 연구계획까지 확정하지 않고 각 기술 담당자의 계획을 함께 반영.

**진행 순서:** 김기웅·박형빈·손유정이 목표·시스템 구성·필요 장비·대표 실험·역할을 담은 1~2쪽 구상안 작성 → 각 기술 담당자의 연구계획을 수합·통합.
