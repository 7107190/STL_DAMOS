# DAMOS

자동차·휴머노이드·배달로봇이 인지 정보를 공유해 **가려진 이상상황을 확인하는 협력 시뮬레이션 시스템**.

**CARLA·Scenic → RGB·LiDAR 인지 → Groth16 직접 공유 → Ego BEV 병합·탐지**

## vvu 실행환경

- 실제 저장 위치: `/data/DAMOS`.
- 기존 `/home/vvu/vv/DAMOS`는 위 위치를 가리키는 링크. 기존 실행 명령 그대로 사용.
- ✅ 2026-11-04 이전 후 회귀 293건·S1~S9·고장 대응 60조건 통과. [경로·검증 결과](docs/usage.md#data-이전-후-검증).

## 연도별 수행내용

| 연도 | 주요 성과 | 상세 |
|---|---|---|
| **2025** | 협력 인지·데이터 수집·미래예측 기반기술, **이상상황 S1~S9 9종 개발** | [2025년 수행내용](docs/2025.md) |
| **2026** | ZKP 공유 통합, **고장 15종·60조건 대응**, 미래 BEV 연구, 기존 시나리오 활용 통합·평가 | [2026년 수행내용](docs/2026.md) |

각 연도 문서 안에서 서브시스템별로 정리.

## 성능지표

| 지표 | 현재 결과 | 상태 |
|---|---|---|
| 1. 모빌리티·데이터셋 | 자동차·휴머노이드·배달로봇 3종, 담당자 시험자료 제출 | ✅ 완료 |
| 2. 처리속도 | 135/135회 완료, **최대 1.791초 ≤ 18초** | ✅ 완료 |
| 3. 이상상황 탐지정확도 | 100건 중 100건 성공, **100% ≥ 70%** | ✅ 완료 |
| 4. 미래예측 | 5,500시점 모두 **5초 지평 충족**, 유효 생성률 100% | ✅ 완료 |

미래예측은 별도 모델·평가 경로. 위 수치는 내부 검증이며 기관 성적서 발급과 구분.
평가 방법·정확한 수치·증빙 위치: [성능지표](docs/metrics.md).

## 보고서·제출 준비

- **2026-12-04 제출:** 2025~2026년 1단계 단계보고서. 2단계 연구계획 포함.
- 사업 유형: **혁신도전형(APRO)·공개경쟁형**. 공식 양식·APRO 대응·남은 작업은 [제출 준비 현황](docs/status.md#12월-4일-단계보고서-제출) 참조.
- ✅ 2차년도 수행내용 통합, 피드백 2·4·5 본문 반영.
- ✅ 박준범 원고 추가 확인: 피드백 1·3, 성능지표 4번 평가 방법·달성 결과.
- 1단계 단계보고서·기술/PoC 통합보고서 1건·2단계 계획 및 기관 증빙 준비 중.
- 전체 체크표: [준비 현황](docs/status.md).
