# DAMOS

자동차·휴머노이드·배달로봇이 인지 정보를 공유해 **가려진 이상상황을 확인하는 협력 시뮬레이션 시스템**.

**CARLA·Scenic → RGB·LiDAR 인지 → Groth16 직접 공유 → Ego BEV 병합·탐지**

## 연도별 수행내용

| 연도 | 주요 성과 | 상세 |
|---|---|---|
| **2025** | 협력 인지·데이터 수집·미래예측 기반기술, **이상상황 S1~S9 9종 개발** | [2025년 수행내용](docs/2025.md) |
| **2026** | ZKP 공유 통합, **고장 15종·60조건 대응**, 미래 BEV 연구, 기존 시나리오 활용 통합·평가 | [2026년 수행내용](docs/2026.md) |

각 연도 문서 안에서 서브시스템별로 정리.

## 성능지표

| 지표 | 현재 결과 | 상태 |
|---|---|---|
| 1. 모빌리티·데이터셋 | 3종 구현. 동시 대수·상호관측·200GB 최종 집계 대기 | 부분 완료 |
| 2. 처리속도 | 135/135회 완료, **최대 1.912초 ≤ 18초** | ✅ 내부 검증·자료 완료 |
| 3. 이상상황 탐지정확도 | 100건 중 97건 성공, **97% ≥ 70%** | ✅ 내부 검증·자료 완료 |
| 4. 미래예측 | 5,500시점 모두 **5초 지평 충족**, 유효 생성률 100% | ✅ 내부 검증·자료 완료 |

미래예측은 별도 모델·평가 경로. 위 수치는 내부 검증이며 기관 성적서 발급과 구분.
평가 방법·정확한 수치·증빙 위치: [성능지표](docs/metrics.md).

## 보고서·제출 준비

- ✅ 2차년도 수행내용 통합, 피드백 2·4·5 본문 반영.
- 박준범 추가 작성 대기: 피드백 1·3, 성능지표 4번 달성 내용.
- 1단계 단계보고서·기술/PoC 통합보고서 1건·2단계 계획 및 기관 증빙 준비 중.
- 전체 체크표: [준비 현황](docs/status.md).
