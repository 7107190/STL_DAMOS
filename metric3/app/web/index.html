앵커별 성공
유효한 시점의 탐지가 0.5초 이상 연속. 5Hz에서 4시점 연속 = 0.6초. 미탐지·누락·평가 불가 시 연속 구간 종료.
전체 성공률

시험 기준·증빙 위치 
시험 건수
새로 생성한 앵커 1개당 1건. 객체 멤버·프레임 수는 독립 시험 건수에 미산입.
탐지 판정
동일 actor ID 정답 영역과 겹치는 8방향 연결 장애물 셀 3개 이상, 센서 수집 시각 기준 0.5초 이상 연속 탐지.
평가 구간
Ego 최초 20m 접근부터 6초, 5Hz 최대 30시점. 성공 조건 충족 시 처리 조기 종료.
실행
현재 CARLA 센서 스트림 → 독립 노드 인지 → Groth16 전송·검증 → Ego BEV 병합 → 별도 정답 대조. 정답은 인지·병합 입력에서 제외.
연속성
미탐지·누락·정답 부족·차도 또는 범위 이탈 시 연속 구간 종료. 처리 지연과 수집 시각을 구분.
